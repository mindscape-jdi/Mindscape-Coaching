# Mindscape Coaching: Level ground

Open `index.html` in a browser. A self-contained page for Mindscape Coaching on why the fee scales with means: communication is only possible between equals.

- A teeter-totter calculator for the fee, (0.04 × net worth + income) ÷ 800 a session or ÷ 80 a season
- Logarithmic sliders from $10,000 to $100 billion of net worth and up to $10 billion of income, exact typed entry (`5m`, `1.2b`) and presets
- A "They pay" slider that tilts the plank when a client pays more or less than the balancing fee
- Short essays: a share, not a price; both ends of the plank; who the fee funds
- `teeter-totter-equals.svg` / `.png`: a static summary graphic

The page is a single HTML file with no build step. Fonts load from Google Fonts; without them it falls back to system fonts.
